# Proposal: 知行快刷 V2.6 — 首页冷启动引导、去英文化、长屏空旷舒展与档案折叠压缩

## Why

经过近期高频迭代与真机验证，发现以下几个明显的体验与认知断层问题：
1. **新用户冷启动归属困惑（核心）**：历史作答为 0 的新用户首次进入小程序时，右侧卡片固定展示 `FOCUS DOMAIN 计算机网络`（甚至带有硬编码兜底），让用户产生“我还没做过题，系统怎么知道我的重点域”的困惑与不适感。
2. **界面英文残留破坏知性调性**：首页双胶囊卡片使用 `DUE TODAY`、`FOCUS DOMAIN`，以及技术标签英文缩写，与「极简、温和、创作与深度学习」的知性暖石膏中文调性冲突。
3. **长屏手机首页空旷下坠**：在 iPhone 15/16 Pro 等较长比例屏幕上，由于首页移除了历史记录，主黑胶囊按钮下方留有超过 200px 的空白奶油底色，视觉重心上浮失衡。
4. **档案页记录冗长拉伸**：「我的」档案页中的「错题巩固本」与「历史练习档案（共 12+ 条）」每个卡片体量厚重、行高与内外边距过大，导致页面无限纵向下滑，浏览疲劳。
5. **头像与昵称修改交互分散**：首页头部点头像直接整页跳转到「我的」，而在「我的」页面中头像与昵称修改缺乏直观的表单操作感和清晰明确的保存反馈。

## What Changes

1. **新用户冷启动引导态（零做题无感破冰）**：
   - 当用户无历史答题记录时，右侧卡片由「重点攻坚」转为「待解锁攻坚 · 完成首测自动定位」；
   - 点击该卡片不会生硬报错，而是自动在下方出题输入框注入「新手推荐热门考点」，引导用户 1 秒直接开刷首测；
   - 产生历史答题数据后，自动无缝切换为「重点攻坚 · [领域名称] · 掌握 N% · 一键开刷 N 题」。
2. **全站界面彻底去英文化**：
   - `DUE TODAY` → `今日待巩固`（无到期时显示 `今日已清零`）；
   - `FOCUS DOMAIN` → `重点攻坚`（新用户显示 `待解锁攻坚`）；
   - `0.1s 秒开错题回忆` → `秒开错题`（零到期显示 `暂无到期 · 查看曲线`）；
   - 保证全站核心标签为简洁直观、优雅自然的简体中文。
3. **首页长屏呼吸感与自适应垂直舒展**：
   - 保持用户选定的**「首页一屏全览零记录」**纯粹原则，坚决不向首页塞入杂乱长列表；
   - 优化 `index-page` 与 `composer-card` 的垂直比例与间距（增大卡片呼吸感、微调输入框高度与外边距），使核心测验卡片在长屏手机上自然匀称居中，告别空旷断层。
4. **「我的」档案页折叠压缩与轻量清单化**：
   - 错题巩固本与历史练习档案默认收拢，仅展示最近 `3~4` 条；
   - 底部提供清爽的「展开全部 N 条 ⌄ / 收起 ‹」折叠胶囊；
   - 压缩条目高度，去厚重外边框，采用更利落的双行轻清单布局，节省 40%+ 垂直空间。
5. **「我的」个人资料表单式直观编辑**：
   - 首页头像/昵称点击保持跳转「我的」页面；
   - 「我的」页面头部个人卡片重构为清晰的表单编辑区：头像右下角附带「📷 换头像」角标（微信端无缝调用 `chooseAvatar`），昵称增加明确的「✎ 编辑」触击态，支持实时聚焦输入与确定保存。

## Impact

- 前端改动涉及：
  - `frontend/src/pages/index/index.tsx` 与 `index.scss`（去英文、冷启动卡片判断、长屏间距舒展）
  - `frontend/src/pages/profile/index.tsx` 与 `index.scss`（档案折叠开关、紧凑清单、表单式资料修改）
- 原型与设计同步：
  - 更新高保真原型 `docs/02-design/prototypes/`，增加冷启动对比态与长屏自适应图。
- 遵循「OpenSpec 规划 → 原型实操验证 → 代码落地 → 双端编译与单测 → 本地 Git 提交」的稳态流程。
