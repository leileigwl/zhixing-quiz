# Spec: 首页冷启动引导、去英文化、长屏呼吸感与档案折叠压缩

## 1. Requirement: 首页全中文与状态映射 (SHALL/MUST)

- 系统 **SHALL** 移除首页所有非必要的英文大写标题，使用简体中文替代：
  - `DUE TODAY` 替换为 `今日待巩固`；
  - `FOCUS DOMAIN` 替换为 `重点攻坚`（新用户态替换为 `待解锁攻坚`）；
  - `0.1s 秒开错题回忆` 替换为 `秒开错题`。
- 当用户历史作答记录数等于 0 时（新用户冷启动）：
  - 系统 **MUST NOT** 展示硬编码或强推的具体领域（如「计算机网络」并显示假掌握度）；
  - 系统 **SHALL** 展示「待解锁攻坚 · 完成首测自动定位」，点击该卡片时系统 **SHALL** 自动在出题输入框中填入推荐初始考点（如 `请基于「核心高频考点」为我生成一套新手自适应摸底测验`）。

## 2. Requirement: 首页一屏全览与自适应呼吸感 (SHALL/MUST)

- 首页 **SHALL** 遵循一屏全览原则，**MUST NOT** 在主按钮下方塞入冗长历史列表。
- 首页样式 **SHALL** 适配现代长屏手机（视口高度 >= 844px），通过自适应垂直分布、微调卡片外间距与输入区域高度，使核心组件重心居中、视觉比例舒展，消除底部大片失衡留白。

## 3. Requirement: 档案页记录折叠与压缩 (SHALL/MUST)

- 「我的」页面历史练习档案 **SHALL** 默认仅展示最近 3~4 条记录。
- 当历史记录总条数大于 4 条时，系统 **SHALL** 提供折叠切换控件：
  - 折叠态显示：`展开全部 N 条记录 ⌄`；
  - 展开态显示：`收起历史记录 ‹`。
- 历史记录条目样式 **SHALL** 采用紧凑双行清单，相比原先大卡片减少至少 35% 单项纵向高度占用。

## 4. Requirement: 个人资料表单式编辑 (SHALL/MUST)

- 首页点击个人信息区 **SHALL** 继续平滑跳转至「我的」页面。
- 「我的」页面顶部个人信息卡片 **SHALL** 提供清晰的编辑态：
  - 头像右下角附带「📷」微标，微信端通过 `chooseAvatar` 唤起微信原生选头像；
  - 昵称右侧提供明确的「修改昵称 ✎」操作按钮，点击后进入内联表单，包含输入框、取消与保存按钮；
  - 保存成功后系统 **SHALL** 局部更新头像/昵称缓存并弹出 Toast 反馈。
