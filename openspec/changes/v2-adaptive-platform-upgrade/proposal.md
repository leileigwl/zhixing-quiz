# Proposal: 知行快刷 V2.0 — 自适应知识画像、间隔重复与分布式异步架构演进

## Why

当前 V1 基线仅实现单次出题闭环，存在以下立项与架构短板：
1. **激励与数据粒度失真**：经验值 `XP` 为单调累加的全局虚荣分，无法反映用户对不同知识域及不同难度题型的真实掌握强度与时间遗忘规律；所有题目压缩在 `quiz_sessions.questions_json` 中，难以支撑单题级错题调度与多维度可视化分析。
2. **出题固定死板、缺少前序回看**：前端固定按 `5` 题出题，既未在冷启动时采集用户对陌生领域的熟悉度，也未依据历史作答正确率/耗时自适应调节难度配比与题量；答题中缺少「上一题」回看解析交互。
3. **单进程架构天花板**：V1 强依赖 `--workers 1`、内存任务集合与嵌入式 Chroma 线程锁，服务重启即丢队列且无法承载水平扩容与延迟错题定时召回。
4. **LangGraph ReAct 黑盒决策耗时过长**：出题固定走多轮 Agent 思考导致耗时高（18~44s），缺少显式可控的“什么时候用搜索接口 vs 直接大模型输出”路由策略与出处透明度。

## What Changes

1. **分布式异步基础设施演进（Multi-Worker + Redis + ARQ + 独立 Chroma Server）**：
   - Docker Compose 增设 `redis:7`、`chromadb/chroma` 独立 HTTP 服务及 `arq` Worker 服务，解除 API `--workers 1` 限制。
   - 使用 Redis 承载分布式滑动窗口限流、任务阶段态、用户知识域画像缓存，并用 ARQ 队列持久化出题、RAG 入库、AI 自动归类、配图与复盘任务。
2. **数据库模型重塑与 AI 自动归类**：
   - MySQL 幂等扩建 5 张核心领域表：`domains`（AI 自动领域归类）、`questions`（单题规范化）、`user_knowledge_mastery`（用户 × 知识域 × E/M/H 难度掌握画像及遗忘稳定性 `stability_s`）、`review_cards`（SM-2 错题复习队列）、`subscribe_quotas`（微信订阅消息余量与偏好）。
   - 废除无意义全局 `XP` 展示，改为「领域掌握度 + 记忆保持率 `R(t)` + 连续复习打卡」。
3. **自适应出题与可控 LCEL 检索路由**：
   - 冷启动采集「陌生 / 略懂 / 熟悉」自评，有历史画像后后端分析掌握分与难度正确率动态决定输出“偏基础少题”或“高阶压测多题”，并支持手动覆盖题量（`3/5/10/15`）。
   - 用 LangChain LCEL 意图路由（`RunnableBranch` + 前端显式联网开关 + URL/时效规则）替代耗时的 ReAct 循环，输出保留稳妥的 Redis 状态缓存 + 2s 轮询。
4. **SM-2 间隔重复、ARQ 延迟召回与学习记忆曲线图谱（原型先行）**：
   - 先更新高保真 6 屏 UI 原型并转图片审阅，新增「学习记忆曲线（保持率衰减）」「未来 7 天待复习预测」与「AI 分类 × 难度三维矩阵」图谱页，答题页新增「上一题（只读回看解析）」；确认参数后再进入编码实现。
