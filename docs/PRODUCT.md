# PRODUCT.md：产品边界

> 状态：线上可部署架构基线已锁定（2026-11-11）。正式上线目标为「微信小程序（个人免费版 / 体验版 + 自有云服务器 Docker Compose + 1Panel HTTPS 反代）」；本地 H5 仅作前端样式与流程调试。详细需求见 [`docs/01-product/PRD.md`](01-product/PRD.md)。

## 产品是什么

**知行快刷（ZhiXing Quiz）** 是一款面向备考复习与技术自测场景的 AI 知识库闯关学习微信小程序。用户输入任意学习主题或上传自己的 PDF/Word/Markdown/文本笔记，后端通过联网检索或私有知识库 RAG 自动生成结构化闯关题库，用户逐题作答获得即时判分与解析，通关后由 AI 生成薄弱知识点复盘报告并累计学习经验值。

## 目标用户

- 需要备考复习或巩固技术八股/专业知识的个人学习者。
- 希望通过“输入材料 → 立即测验 → 错题解析 → 复盘报告”快速检验掌握程度的微信小程序用户。

## 第一版（上线版）做什么

- **静默身份登录与 JWT 会话**：小程序启动自动静默 `wx.login` 获取服务端签发的 JWT；Token 失效时前端静默重登一次，保证无感体验同时阻断公网匿名调用。
- **自由主题智能出题（联网增强）**：用户输入主题/文本/URL，后端通过异步任务生成 3~10 道单选/多选/判断题，可选开启 Tavily 联网搜索补充最新背景知识。
- **私有知识库管理（RAG 出题）**：支持上传 `.pdf` / `.docx` / `.md` / `.txt`（单文件 ≤10MB、每人 ≤10 篇），后台异步切块向量化存入 Chroma（按用户隔离），支持基于指定文档出题与级联删除。
- **逐题闯关与 AI 复盘报告**：本地即时判分与解析、记录答题耗时，交卷后由 AI 生成掌握/薄弱知识点、三句总结、学习建议与分享金句，并累加经验值（XP）。
- **题目 AI 配图（并发限流 + 容错降级）**：可选为题目生成教学配图，使用信号量限流与每日额度控制，持久化到腾讯云 COS（未配置 COS 时可回落自有 HTTPS 服务器静态存储），配图失败绝不阻断出题主流程。
- **个人学习档案与历史回看**：统计总 XP、闯关次数、累计答对题数与平均正确率，分页查看历史闯关并回看原题与复盘报告，支持修改昵称和头像。

## 第一版明确不做什么

- 不做微信云托管（后端独立部署在自有云服务器 Docker Compose + 1Panel）。
- 不对外公开发布独立 H5 网页用户端（H5 仅作本地开发/样式预览；生产环境彻底关闭免微信开发态登录）。
- 不做公网免 JWT 匿名调用 AI 出题/报告接口（防止公网爬虫刷爆大模型与搜索额度）。
- 不做多人实时 PK、全局排行榜、付费订阅、支付链路或后台管理系统。
- 不做音视频/PPT 解析，不引入跨进程分布式队列或自定义代码执行插件。

## 支持的核心用户操作

1. 打开小程序（自动完成静默 JWT 登录）→ 在「闯关」Tab 输入主题/选配图开关 → 发起出题 → 2 秒轮询后进入答题页。
2. 切换到「知识库」Tab → 上传个人复习文档 → 等待异步解析就绪 → 点击「开始闯关」基于该文档定向出题，或删除旧文档。
3. 在「闯关答题」页逐题作答查看解析 → 交卷跳转「复盘报告」查看薄弱点与金句。
4. 切换到「我的」Tab → 查看累计 XP 与正确率统计、修改昵称头像、点击历史记录回看往期题目与报告。
