1. 参考官网提炼的版式要点（只借鉴结构，不用其素材 / 文案 / logo）

  • 顶部细导航：品牌 + 锚点 + 一个强 CTA（登录）；滚动时吸顶、半透明毛玻璃。
  • Hero：眉标胶囊（一句定位）→ 两行大标题（关键词渐变着色）→ 一段说明 → 主 / 次两个按钮 → 一行信任小字；右侧放产品画面卡片（本项目为 CSS/SVG 绘制，标「界面示意」）。
  • Hero 下方一条「事实条」（4 格大字 + 小字）。参考站多用数据条；本项目没有可公开的真实统计，只写产品能力（3 题起 / SM-2 / 4 种格式 / 3 端同步），不虚构用户数。
  • 功能分区：小标题（kicker）+ 大标题 + 一句说明 + 卡片网格，每张卡一个主色图标块 + 要点列表；各功能一种辅助色。
  • 编号流程 01 / 02 / 03，浅色渐变底分区，与上下分区拉开节奏。
  • 原理分区：左文右图（曲线示意图，明确标「示意」）。
  • FAQ 折叠 → 收尾 CTA 渐变色带 → 简洁页脚（品牌、链接、版权、备案号链接工信部）。

5. 排布规则

  • 断点不变：<768 手机底部 Dock；768–1099 iPad 竖屏保留底部 Dock（用户 2026-11-25 规则）；≥1100 左侧 232px 侧栏。
  • iPad 偏小的根因：设计稿 px 经 pxtransform 转 rem（1rem = 40 设计 px），V2.9 根字号封顶 22Px，iPad 上与手机同大。V3.0：≥768 根字号 clamp(24Px, 2.5vw, 26Px)，≥1100 为 24Px，≥1440 为 25Px；平板内容最大宽 720 → 880。
  • 首页平板：两列网格 —— 快捷卡（2 张）/ 发起新测验 / 本周完成题数 + 学习概览（进度环 + 大数字）；新用户换成三步引导。宽屏：左 7 份发起测验，右 5 份快捷卡 / 概览 / 本周。
  • 备案页脚：所有 .zx-rpage 纵向 flex，页脚 margin-top:auto，内容不足一屏也贴底，位于 Dock 留白之上；门头页页脚含备案号并链接 https://beian.miit.gov.cn/ 。
  • 空状态：三步引导（上传资料 → 出一组题 → 看记忆曲线），每张示意小图左上角标「示意」，与真实数据区分。
