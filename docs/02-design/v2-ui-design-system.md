## 1. 核心视觉定调与留白纪律

1. **一屏一主调，拒绝糖果色堆砌**：
   - 全局画布底色统一使用 **暖石膏 `#F6F5F1`**（答题阅读页可升亮至纯白 `#FFFFFF` 提升阅读对比度），卡片主表面为 **纯净白 `#FFFFFF`**。
   - 单屏高亮色块**严格控制在 1~2 块低饱和柔和色**，靠 **大留白（42%+）+ 清晰字阶对比 + 黑曜石高反差文字/按钮** 建立高级感。
2. **禁止元素**：
   - 严禁出现厚重深色描边、廉价霓虹外发光、会员/付费墙入口、以及用代码圆球拼出的拙劣动物造型。
   - 全站禁止使用无关竞品产品名，记忆曲线统一命名为 **「学习记忆曲线」**（`R(t) = e^(-t/S)`）。

## 3. 图标与微缩插画规范（替代旧版几何球造型）

- **设计语言**：对齐 `v2-editorial-3palettes.html` 方案 B / 内页示范，采用 **软圆角积木层叠 + 磨砂半透明几何微缩图标**（SVG 或轻量 PNG 静态图，如双卡片叠层、双圆交叠靶心、错落文件卡）。
- **构图纪律**：
  - 图标内部元素不超过 `3` 个基础几何层，统一圆角半径（卡片徽标 `rx=9~12`，点缀高光用半透明纯白 `rgba(255,255,255,0.72)` 叠加黑曜石 `#18191E` 对比）。
  - 如后续引入高精 3D 角色（例如等待生图配额或外部设计资产），每屏仅允许出现 `1` 处克制置顶或角落点缀，严禁强塞回代码拼接圆球动物。

## 4. 按键排版、间距与页面组件对照表

实现 `frontend/src/pages/` 时严格按以下结构与防折行规则对齐：

### 4.1 首页（出题入口与复习节律）
1. **顶部 Greet 行**：左侧 `34x34px` 圆形字标（`#E9E6DC`）+ 粗体问候与副标题（连续天数）；右侧 `32x32px` 纯白搜索圆按钮。
2. **7 日节律条（`MOVEPOP` 标志组件）**：7 列等宽网格，周一~周日竖排（星期简写 + 两位日期）；**今日态**使用黑曜石实心竖胶囊（`background: #18191E; border-radius: 999px`，白字）。
3. **双卡 Bento Grid（严格 2 列，无边框，`24px` 圆角，`gap: 12px`，`height: 174px`）**：
   - 左卡（`#F4D06F` 奶油黄）：右上角 micro tag `DUE TODAY`（半透明黑底胶囊）+ 微缩卡片图标 + `04 错题 · SM-2 到期 · 优先巩固`。
   - 右卡（`#CBE5F5` 雾天蓝）：`ADAPTIVE` + 微缩靶心图标 + 当前主攻域（如 `RAG 架构 · 掌握 74% · 建议 6 题`）。
4. **出题输入舱（`#FFFFFF`，`26px` 圆角，`padding: 18px`）**：
   - 标题标签 + 主题输入框（支持选中知识口袋中的文档）。
   - **按键第一行（DeepSeek 胶囊组 + 题量展示）**：左侧 `🌐 智能搜索` + `🎨 配图` 胶囊（`height: 29px; padding: 0 11px; border-radius: 999px; white-space: nowrap`）；右侧当前模式文案（如 `6 题模式`，`white-space: nowrap`）。
   - **按键第二行（题量 / 熟悉度分段控制）**：左侧小标签（`出题节奏` 或 `当前熟悉度`）+ 右侧 `seg-bar` 胶囊分段条（`3题 / 自适应 / 10题` 或 `陌生 / 略懂 / 熟练`，每项 `white-space: nowrap`，**禁止把 DeepSeek 胶囊与 `seg-bar` 硬挤在同一行导致中文竖排折行**）。
   - **主行动按钮**：全宽黑曜石胶囊（`height: 48px; border-radius: 999px; background: #18191E`，左文右箭头 `→`）。
5. **底部黑曜石悬浮胶囊 Dock（`MOVEPOP`）**：
   - 距底 `16px`，左右留距 `18px`，`height: 58px; border-radius: 999px; background: #18191E`。
   - 内含 4 个 Tab 图标，**当前激活 Tab 使用 `40x40px` 纯白正圆底座**反色高亮图标。

### 4.2 知识口袋页（`DAYPATCH`）
- 顶部标题 + 右上黑色胶囊按钮 `+ 上传文档`。
- 提示条：`支持 PDF / Word / MD 自动切片归档` + 右侧领域计数（`white-space: nowrap`）。
- `2x2` 口袋网格（`height: 176px; border-radius: 22px; gap: 14px`）：背后斜插旋转 `±3deg` 的纯白纸质摘要卡，前景用 `backdrop-filter: blur(12px)` 半透明磨砂袋口 + 顶部 `1px dashed` 缝线包裹领域名称与文档数/保持率。

### 4.3 极净刷题与「`< 上一题`」只读回看
- **顶部**：`领域 · 第 X / N 题` + 右侧自适应难度胶囊 + 顶部横条分段进度指示器。
- **题干与选项**：衬线/高可读标题 + 4 枚大圆角单选卡（`border-radius: 16px`，正确态浅绿底 `#F0F9F3` 配绿色钩）。
- **解析区**：提交后 `220ms` 缓冲平滑展开，带来源角标（如 `知识库 + 搜索核验`）。
- **底部双栏按键（固定 112px + 1fr，`gap: 10px`）**：左侧白底描边 **`‹ 上一题`** 胶囊（进入已提交题只读回看态，禁用篡改得分）；右侧黑曜石 **`下一题 →`** 主胶囊。

### 4.4 复盘与学习记忆曲线页
- **3 格核心指标条**：`本次准确率`、`平均耗时`、`连续复习天数`（纯白圆角卡，大字数字 + 小号说明，废除无意义经验值 `XP`）。
- **学习记忆曲线 SVG 图**：绘制 `R(t) = e^(-t/S)` 复习前衰减虚线与今日复习后回升实线，标注 **`50%` 临界虚线预警** 与明确数据标签（留足上下安全边距，不与曲线重叠）。
- **本周复习节律**：7 列纤细竖条圆角柱图（轨道 `#EFEFF3`，历史柱 `#CBE5F5`，今日柱 `#14151A`）+ 底部全宽黑曜石 CTA（`开启明日 ARQ 到期提醒 →`）。
