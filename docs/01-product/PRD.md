# 知行快刷｜详细产品需求文档（PRD）

> 本文档为 [`docs/PRODUCT.md`](../PRODUCT.md) 的细节展开版，记录完整的页面交互需求、模块边界与验收口径。

---

## 1. 产品定位与上线目标

- **产品名称**：知行快刷（ZhiXing Quiz）—— AI 知识库自测与智能闯关微信小程序
- **线上部署形态**：微信小程序（个人免费版 / 体验版扫码可用，后续可直接提审正式版）+ 自有云服务器 Docker Compose + 1Panel HTTPS 域名反代。
- **本地开发调试形态**：Taro 4 同时编译 `weapp`（微信开发者工具调试）与 `h5`（浏览器快速调样式与走查接口）。
- **解决的核心痛点**：
  1. 备考或技术学习时只看文档/笔记容易走神、难检验真实掌握度；
  2. 直接向通用大模型提问容易偏离自己手中的教材/讲义且知识易过时；
  3. 微信小程序网络请求存在 **60 秒超时** 上限，而检索 + 结构化出题 + 配图通常耗时 30~90 秒。

## 2. 用户角色与业务闭环

### 2.1 身份与登录策略（静默 JWT + 全链路受保护）
- **微信小程序用户**：打开小程序时，`app.ts` 自动静默调用 `Taro.login()` 换取后端签发的 30 天 HS256 JWT，用户无需手动点击登录即可使用全部核心功能；若请求返回 `4010`（Token 过期或失效），前端自动单飞静默重登一次并重放请求。
- **本地开发与 H5 样式预览**：仅在非生产环境且显式开启 `ALLOW_DEV_LOGIN=true` 时提供 `POST /api/v1/user/dev-login`，方便在 Chrome H5 模式下联调上传文档、出题与历史记录；生产环境彻底封禁此接口。

### 2.2 两条核心出题闭环

```text
路径 A（自由主题速刷）
  闯关首页输入主题/文本/URL（可选开启 AI 配图）
  → 校验 JWT + 限流 + 敏感词 → 创建异步任务（task_id 秒级返回）
  → 后台 LangGraph ReAct 调 Tavily 联网搜索（无 Key 时平滑降级）+ DeepSeek 生成 5 题
  → 可选 Semaphore 并发生成配图 → 落库 quiz_sessions → 前端每 2 秒轮询完成跳转答题页

路径 B（私有知识库 RAG 定向出题）
  知识库 Tab 上传 PDF/DOCX/MD/TXT（≤10MB，每人 ≤10 篇）
  → 后端立刻返回 processing，后台线程加载切块（1000/150）+ Embedding 写入 Chroma (kb_user_{id})
  → 状态变为 ready → 点击「开始闯关」（携带 doc_id）
  → 后台 LangGraph Agent 闭包锁定 user_id/doc_id 优先检索文档，必要时按需联网补充
  → 结构化出题 → 闯关答题 → AI 复盘报告 + 累加 XP
```

## 3. 页面架构（3 个底部 Tab + 2 个二级页面）

> 样式与视觉布局将在 **Phase 2** 根据前端样式输入先绘制交互式 HTML 原型图，确认后再写 `frontend/` 代码。

| 页面 | 路由 | 类型 | 关键交互与修复要点 |
| --- | --- | --- | --- |
| **闯关首页** | `pages/index/index` | Tab 1（闯关） | 顶部用户简况与 XP 徽章、学习主题输入框、示例标签、配图开关、开始出题按钮、轮询进度提示、最近闯关记录入口 |
| **知识库页** | `pages/knowledge/index` | Tab 2（知识库） | 上传限制提示、上传按钮（同时兼容微信小程序 `chooseMessageFile` 与 H5 `<input type="file">`）、文档状态卡片轮询、一键「开始闯关」、删除确认 |
| **我的页面** | `pages/profile/index` | Tab 3（我的） | 头像/昵称展示与编辑、4 项统计（总 XP、闯关数、答对数、平均正确率）、历史闯关分页列表与回看入口 |
| **闯关答题页** | `pages/quiz/index` | 二级页 | 顶部进度（第 X/Y 题）、题型/知识点标签、题目配图展示、单/多/判断作答、即时高亮与解析、记录每题耗时；**修复**：题库数据经本地会话缓存传递，避免 URL 查询串过长截断 |
| **复盘报告页** | `pages/report/index` | 二级页 | 掌握度与对错统计（绿色正确/红色错题）、分档评语、掌握/薄弱知识点标签、三句总结、建议与金句、支持从「我的」历史记录按 `quizId` 回看 |

## 4. 功能需求与生产加固细节

1. **异步任务防超时与容错**：
   - `POST /api/v1/quiz/generate/async` 校验 JWT、分钟级限流、内容安全与 `doc_id` 归属就绪后，秒级返回 `task_id`。
   - 后台协程设置外层超时熔断（默认 180 秒）；服务端重启时自动清理遗留的 `pending`/`running` 任务与 `processing` 文档为 `failed`，防止前端无限轮询。
2. **私有知识库多用户隔离**：
   - 支持 `.pdf` / `.docx` / `.md` / `.txt`，空文件拦截、单文件 ≤10MB、每人 ≤10 篇。
   - Chroma 按 `kb_user_{user_id}` 分集合存储，使用 `check_embedding_ctx_length=False` 兼容百炼/硅基流动等 OpenAI 兼容接口；检索工具经 Python 闭包锁定 `user_id` 与 `doc_id`。
   - 阻塞型的文件加载切分与向量化写入使用 `asyncio.to_thread` 放进线程池，避免卡住 FastAPI 异步主循环。
3. **题目 AI 配图（并发限流 + 存储降级）**：
   - 每日每用户默认限额 `20` 张，单批次使用 `asyncio.Semaphore(5)` 控制并发。
   - 优先上传腾讯云 COS 获得永久 HTTPS 链接；若生产/本地未配 COS 且开启静态回落，写入服务器持久化静态目录 `/static/quiz-images/` 并拼接 `PUBLIC_BASE_URL` 返回可访问 HTTPS 地址；任何生图异常均降级为纯文字题，不阻断主流程。
4. **计分、报告与 XP 规则**：
   - 精准统计答对题数与整数百分比正确率；报告生成成功后登录态落库 `answer_records` 与 `reports`，并给用户增加 `10 + 答对题数 × 2` 点 XP。
